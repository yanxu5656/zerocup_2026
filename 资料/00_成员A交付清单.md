## 五、怎么用打包脚本

```powershell
# Windows 自带 PowerShell（本机可用）
powershell -NoProfile -ExecutionPolicy Bypass -File tools\pack-release.ps1 -Source web -Out dist

# PowerShell 7
pwsh -NoProfile -File tools\pack-release.ps1 -Source web -Out dist
```

约定三条，脚本会检查：

- 网站源码放在 `web/`（或 `-Source` 指向的目录），根目录必须有 `index.html`；
- 脚本统一放在 `</body>` 之前，**不用 `defer` / `async`**（单文件版内联后它们会失效）；
- 不出现 `http(s)://` 外链，不引入任何第三方库。

脚本会生成 `dist/灯影_单文件版/`、`dist/灯影_工程版/` 和两个同名 zip，并输出体积报表与合规扫描结果。
