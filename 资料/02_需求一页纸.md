## 一、一句话需求

做一个 **5 页的纯原生静态网站**，用"点灯—弄影—看戏—见人—续灯"的动线，让 18–35 岁用户在 **3 分钟内**看懂中国皮影戏，并**至少动手玩一次、愿意转发一次**。

## 二、目标用户与价值

| 用户 | 他们的问题 | 我们给的答案 |
| --- | --- | --- |
| 刷到链接的路人 | 这是什么？值得看下去吗？ | 首屏一盏会亮起的灯箱 |
| 想带孩子体验的家长 | 有能动手的东西吗？ | 3 关拖拽，1 分钟通关 |
| 带审视眼光的同行 | 做得用心吗？ | 七道工序的镂刻细节、准确的流派与史实 |

**成功标准**：3 秒看懂 → 30 秒上手 → 3 分钟记住一个细节 → 愿意把链接发出去。

## 三、页面架构（5 页 + 1 条主线）

| 编号 | 页面 | 文件 | 这一幕要解决 | 必须有（内容） | 关键交互 | 离开时的情绪 |
| --- | --- | --- | --- | --- | --- | --- |
| P0 | **掌灯**（首页） | `index.html` | 建立氛围与入口 | 灯箱主视觉、一句话主张、三入口、全站导航、页脚 | 点灯（点亮全场）、光晕跟随、三入口悬浮 | 好奇 |
| P1 | **溯影**（源流·流派·工序） | `origin.html` | 建立知识框架 | 时间轴 6 节点、五大流派、七道工序 | 滚动触发时间轴、流派切换、工序放大看刀口 | 懂了 |
| P2 | **弄影**（核心体验） | `play.html` | 交付"玩"的体验 | 弄影台三关、影窗剧场三剧目、灯与幕控制 | **拖关节摆姿势**、调灯、拉幕、剧目切换、字幕 | 玩过 |
| P3 | **见人**（传承人与物） | `people.html` | 建立情感连接 | 传承人档案（≥2 位）、工具墙、口述引语、老照片位 | 卡片翻转、引语逐字浮现、工具悬停解说 | 敬重 |
| P4 | **续灯**（当代·参与） | `future.html` | 落到当下与行动 | 当代表达 3 案例、纹样库、寄语、致谢 | 纹样点击放大、寄语输入、回到第一幕 | 想参与 |

**跳转关系**

```
                    ┌──────── 全局导航（5 项，每页常驻） ────────┐
                    │                                              │
  P0 掌灯 ──三入口──┼──> P1 溯影 ──页尾"下一幕"──> P2 弄影 ──通关──> P3 见人 ──页尾──> P4 续灯
     ▲              │        ▲                       │                                        │
     └──────────────┴────────┴──── 页脚"回到第一幕" ◄┴────────────────────────────────────────┘
```

- 全局导航：掌灯 / 溯影 / 弄影 / 见人 / 续灯（5 项，≤720px 折叠为汉堡菜单）。
- 每页页尾固定一个"下一幕 →"巨型链接，承担主推进；页脚保留全站目录。
- P2 通关后自动出现"谢幕 · 去看他们的手"跳往 P3，把游戏成果转成叙事。
- 跨页状态：P2 通关状态存 `localStorage`，回到首页时三入口中的"弄影"卡点亮为"已通关"。

## 四、核心交互主线（黄金动线，评审会照着走这一遍）

1. **点灯**：进入 P0，整站是暗的，只有一盏没点燃的灯和一句"灯亮起来，皮影才活"。用户点灯 → 全场亮起、皮影从幕布后浮出。
2. **溯影**：滚动看时间轴，看到"七道工序"时点击"镂刻"，刀口放大，明白一张牛皮要挨三千刀。
3. **弄影**：进入 P2，三关拖拽——① 抬右臂亮相 ② 双臂开弓 ③ 提腿跨马并拉开幕布。每关吸附成功都有一声"咔"的光环。
4. **看戏**：通关解锁剧场，选《三打白骨精》片段，字幕逐句浮现，幕布随剧情推拉。
5. **见人 · 续灯**：从戏里走出来，见到做这双手的人，最后在 P4 点亮自己的一盏灯（寄语 + 生成一张自己的皮影）。

> 这 5 步必须全程无死路、无加载等待、无二次点击才能继续。任何一步卡住，都算 P0 缺陷。

## 六、非功能要求

| 类别 | 要求 |
| --- | --- |
| 运行环境 | Chrome 129 为主；兼容 Edge / Firefox / Safari 最近两个大版本 |
| 控制台 | **零报错、零警告、零 404**（含图片、字体、favicon） |
| 依赖 | 零第三方库（禁止 Bootstrap / Element / jQuery / Tailwind CDN）、零外链字体图片、零 CDN |
| 响应式 | 1920 / 1440 / 1024 / 768 / 390 五档，任意档位无横向滚动、无遮挡、无溢出 |
| 性能 | 首屏 HTML+CSS+JS ≤ 800 KB（未压缩）；单页 SVG 总量 ≤ 150 KB；LCP < 2.5s（4G）；动画 60fps |
| 交互反馈 | 所有可点元素有 hover / active / focus 三态；300ms 内有视觉反馈 |
| 无障碍 | 语义标签、正文对比度 ≥ 4.5:1、全键盘可达、focus 可见、`prefers-reduced-motion` 降级 |
| 内容准确 | 史实、流派、工序名称、传承人信息须可核查，C 提供来源 |
| 版权 | 全站素材自制或可商用；页脚注明"本站图文素材均为学习创作，如有版权问题请联系删除" |

## 七、验收标准（DoD，全部满足才算完成）

1. 打开 `index.html`，5 页互跳无死链，返回不丢滚动位置。
2. 黄金动线 5 步全程可完成，弄影台三关可通关且可重置。
3. Chrome 129 控制台**零红字**，网络面板无 404，无第三方请求。
4. 五档视口下无横向滚动、无元素遮挡（截图留证）。
5. 断网状态下全站可正常浏览（单文件版双击即开）。
6. 键盘走完全站主流程；`prefers-reduced-motion` 下无强制动画。
7. README、素材说明、版权声明、打包脚本齐全，双版本 zip 可解压即用。
