## 一、站点地图

```
灯影 · 一盏灯照见千年
├── index.html          第一幕 · 掌灯      （氛围 · 入口）
├── origin.html         第二幕 · 溯影      （源流 · 流派 · 工序）
├── play.html           第三幕 · 弄影      （弄影台 · 影窗剧场）

└── future.html         第五幕 · 续灯      （当代表达 · 纹样 · 寄语）
```

- 页面命名用拼音，避免中文路径在不同系统/压缩包里的编码问题。
- 全站不使用前端路由，`<a href>` 直接跳页，保证双击文件也能跑。
- 全站唯一入口 `index.html`；不建设 404 页，所有链接必须可达。

### P2 · 弄影（`play.html`）—— 全场核心，投入最多

**这一幕的任务**：让人亲手演一次。这是全站唯一"必须玩"的页面，也是评审记住我们的地方。

页面分上下两段：**上段 · 弄影台**（游戏），**下段 · 影窗剧场**（观影）。

#### 2A 弄影台

**舞台构成**
- 灯箱（16:9 或 4:3，移动端 1:1.2 竖版）
- 幕布（带轻微褶皱渐变 + 噪点）
- 皮影（SVG，4 个可操作关节：右臂、左臂、右腿、左腿；关节处留 2px 空隙表示缀结）
- 三枚进度灯（对应三关）
- 底部控制条：重置 / 提示 / 完成度

**三关设计**

| 关 | 目标姿势 | 操作 | 判定 | 通关反馈 |
| --- | --- | --- | --- | --- |
| 第一关 · 亮相 | 右臂上举 60° | 拖右臂关节 | 角度误差 ≤ 8° | 皮影停住，唱词「一亮相，满堂彩」逐字出现 |
| 第二关 · 开弓 | 右臂 60° + 左臂 −30° | 依次拖两个关节 | 两关节均 ≤ 8° | 幕布轻微震动，光晕脉冲一次 |
| 第三关 · 跨马 | 双臂保持 + 右腿抬起 40° + 幕布拉到 88% | 拖腿 + 拖幕布边缘 | 三条件同时满足 | 全场亮度提升，印章「成」落下，解锁剧场 |

**判定与手感（必做，差一点就不像"高级"）**
- 吸附：进入 ±8° 时自动吸附到目标角，且吸附瞬间关节处出现一圈金色光环（600ms 消散）。
- 反向阻尼：超出目标 ±25° 时阻力增大（拖拽位移乘 0.6），制造"到位了"的手感。
- 引导：静止 3 秒后目标关节呼吸高亮（2 次）；6 秒后浮出手势示意。
- 错误容忍：**永不出"失败"二字**，只给"再来一次"与"提示"。
- 重置：一键回到初始姿势，进度灯清零，不清除已通关记录。

**状态机**

```
idle ──pointerdown──> dragging ──release(未达阈值)──> idle
  │                      │
  │                      └──enter ±8°──> snapped（锁定该关节）
  │
  └──全部条件满足──> complete ──1200ms──> transition（下一关 / 解锁剧场）
```

- `idle`：仅目标关节可拖，其余关节 `pointer-events:none`，降低误操作。
- `snapped`：关节锁定并显示光环；如目标变化（回到上一关）则解锁。
- `complete`：禁止继续拖拽，播放一次性完成动效。
- 任何阶段允许"重置"回到 `idle`。

**无障碍与键盘**
- 每个关节是 `<button>` 或 `tabindex="0"` 元素，带 `aria-label="右臂关节，当前 32 度"`。
- `←/→` 微调 1°，`Shift + ←/→` 微调 5°，`Enter` 确认吸附。
- 键盘路径必须在 30 秒内可通关（评委会试）。

## 五、视觉方向（给 B 的 brief，最终由 B 定稿）

### 5.1 配色

| 角色 | 色值 | 用途 | 备注 |
| --- | --- | --- | --- |
| 墨（背景） | `#16110D` | 暗场底色 | 不用纯黑，留一点褐色 |
| 幕（次级面） | `#241C16` | 卡片、幕布 | 与墨差 12% 亮度 |
| 皮（亮面） | `#F3EADC` | 亮场底、纸面 | 宣纸白 |
| 灯（主强调） | `#E8B45A` | 灯光、金线、焦点 | 主 CTA 用它 |
| 朱（次强调） | `#B4352B` | 印章、警告、选中 | 面积不超过 5% |
| 青（点缀） | `#2E6B4F` | 纹样、次要标签 | 少量用 |
| 文字主 | `#F3EADC` / 暗场；`#241C16` / 亮场 | — | 对比度 ≥ 4.5:1 |

> 全站两套场景（暗场 / 亮场）不是两套主题，而是同一套变量在 `--lamp` 上的取值：`--lamp: 0.15 ~ 1`。B 只需定义一次变量映射。

### 5.2 字体与字阶

- 标题：宋体族（`Songti SC, Noto Serif SC, Source Han Serif SC, STSong, SimSun, serif`），字重 600，字距 `.12em`。
- 正文：黑体族（`PingFang SC, Microsoft YaHei, Noto Sans CJK SC, sans-serif`），14–16px，行高 1.85。
- 数字/英文：`Georgia, "Times New Roman", serif`，用于编号（壹贰叁肆伍）。
- 字阶：56 / 40 / 28 / 20 / 16 / 14 / 12，全站只用这 7 档。
- 竖排：仅用于页名与题记（`writing-mode: vertical-rl`），**不用于正文**。

### 5.3 栅格与留白

- 12 列栅格，gutter 24px，内容最大宽 1440px。
- 页边距 `clamp(20px, 5vw, 112px)`。
- 区块间距：桌面 120px，平板 88px，手机 64px。
- 留白原则：一屏一个焦点，宁可空，不可挤。

### 5.4 质感与图形

- 幕布：径向渐变 + SVG `feTurbulence` 噪点（静态，一次生成，勿每帧计算）。
- 皮影：单一描边色 + 镂空纹，**不做写实渐变**；关节处留 2px 空隙表示缀结。
- 光：所有高光用 `radial-gradient` 叠加 `mix-blend-mode: screen`，不用大面积 `filter: blur`。
- 图标：1.5px 线性，圆角 2px，统一 24×24 画布。

### 7.2 硬约束

- 零第三方库、零外链、零 CDN；字体只列系统字体栈。
- 每页独立可打开，不依赖构建工具；`file://` 协议下功能完整（注意：`fetch` 本地文件会失败，数据一律内联或写进 JS）。
- 不引入 ES Module 的跨文件 `import`（`file://` 下 CORS 会拦截）；脚本用经典 `<script defer>`。
- 交互状态一律用 `data-*` 属性 + CSS 类，避免内联 style 满天飞（DIY 实时预览除外）。
- 所有图片 `alt` 必填；装饰性 SVG 加 `aria-hidden="true"`。
- 禁止 `alert` / `confirm` 等阻塞式弹窗。
- 控制台零输出（调试代码提交前删除）。
