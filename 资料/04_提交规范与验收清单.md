## 三、打包流程

```powershell
# 在仓库根目录执行（网站源码放在 web/ 时可用默认参数）
powershell -NoProfile -ExecutionPolicy Bypass -File tools\pack-release.ps1 -Source web -Out dist

# 装了 PowerShell 7 的机器
pwsh -NoProfile -File tools\pack-release.ps1 -Source web -Out dist

# 如果源码就在根目录（index.html 与 assets/ 同级）
powershell -NoProfile -ExecutionPolicy Bypass -File tools\pack-release.ps1 -Source . -Out ..\dist
```

> 源码目录根层必须有 `index.html`；脚本统一放在 `</body>` 之前，**不要用 `defer` / `async`**（单文件版内联后它们会失效，脚本会报错提醒）。

脚本会做四件事：
1. 生成单文件版（内联 CSS/JS/图片为 data URI）。
2. 生成工程版（纯复制，剔除 `资料/`、`TEST/`、`.git/` 等，并放入根目录的 `README.md`）。
3. 合规扫描：外链、第三方库关键字、超大文件、缺失页面。
4. 分别打 zip 并输出体积报表。

**再生成匿名版**（独立脚本，自检不过会以退出码 1 拒绝）：

```bash
node tools/anonymize.mjs web dist/匿名版
```

**最后按 2.3 组装三个包**：

```powershell
# 两个子包（各自带一层目录）
Compress-Archive -Path dist\灯影_工程版 -DestinationPath "dist\2026-零杯壹组-灯下黑-闫煦-完整版本.zip" -Force
Compress-Archive -Path dist\匿名版      -DestinationPath "dist\2026-零杯壹组-灯下黑-闫煦-匿名版本.zip" -Force

# 总包（只放上面两个子包）
Compress-Archive -Path "dist\2026-零杯壹组-灯下黑-闫煦-完整版本.zip","dist\2026-零杯壹组-灯下黑-闫煦-匿名版本.zip" -DestinationPath "dist\零杯壹组-灯下黑-闫煦.zip" -Force
```

**打包后必做**：把总包解压到**桌面上另一个目录**再打开一遍（不要在源码目录里测，缓存会骗人）。
