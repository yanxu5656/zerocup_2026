### 3.3 页面级问题清单（截图对照）

**P0 首页**

- 右侧"灯影"印章是**空心方框**，像占位符（`pages.css` 的 `lede__seal`）。
- 点灯只有亮度变化，缺 03 文档承诺的 M01"皮影从幕布后浮出"、M02"灯晕跟随鼠标"（`main.js` 无 mousemove 实现）。
- 三入口卡是纯文字块，hover 只抬升，没有"剪影微动"。

**P1 溯影**

- 时间轴是**纯文字列表 + 一条竖线**，"影"的意象完全没出现。
- 五大流派的插画是一条**波浪线**（`#pat-cloud`），与"陕西/唐山/四川"无对应关系。
- 七道工序是米色带上 7 个小方块，下方大片空白，**像没做完**。
- 工序弹层只有文字，没有"刀口细节图"（03 文档 1.4 明确要求"必须可放大看清"）。

**P2 弄影（核心）**

- 皮影本体像**黑色火柴人**：无头茬、无靠子、无镂空、无兵器，只有 4 根圆柱肢体。这是全站最该精致的地方。
- 幕布是红白竖条纹，**像包装纸**，不像布。
- 剧场三个剧目共用**一张抽象山景 + 两个色块人**，切剧目只换字幕不换画面。
- **剧场硬锁**：未通关时 `nextBtn` 直接 return（`theater.js:146-152`），评委点"下一句"毫无反应 → 这是"反人类"体验，直接伤"流畅性 5 分"。
- 键盘通关实际不可达：步进 1°/5°，到 −150° 需 30 次 `Shift+→`，三关 60+ 次按键，与"30 秒内通关"（03 文档 T09）不符。

**P3 见人**

- 传承人卡正面只有**一个圆点图标**，没有人像、没有手、没有工具。
- 工具墙 5 个线性图标 + 一行说明，卡片内 60% 是空白。
- 引语区是 4 条带左边线的段落，缺"口述"的呼吸感。

**P4 续灯**

- 8 个纹样**不像纹样**：龙纹=螺旋线、云纹=三道波浪、万字=十字加折、雪花锦=六边形。评委一眼能看出是随手画的。
- DIY 皮影是"圆头 + 梯形身体"，无脸谱、无纹样层可见（`#diyPatternLayer` 有但视觉几乎不可见）。
- 三个"当代表达"案例只有图标 + 两行字，没有作品感。

- README 数字全部改成"可复现的命令 + 实测值"

### 4.2 第二层 · 记忆点（5 天，决定上限）

只做两件事，但做到"能截图当封面"：

1. **重绘皮影本体**（见 5.15 规范）：头茬（净/旦/丑）+ 靠子 + 4 关节 + 3 根竹签，全部用 `fill-rule="evenodd"` 做镂空，光能透过去。
2. **剧场三出戏各画一套分层场景**：远景（山/云/城）、中景（桌/桥/洞）、角色（2–3 个），每句台词切换一次图层位移，形成"镜头在动"的错觉。

### 4.3 第三层 · 高级感（4 天）

- 光的三层模型（5.5）
- 材质：幕布噪点、牛皮纤维、纸纹（全用 CSS/SVG，不引外部图）

- 微交互补全：M02/M06/M10/M13 + 全站 focus-visible 统一

### 4.4 明确不做（防散）

| 不做                    | 理由                                               |

| 后端 / 登录 / 数据库         | 手册明确"后端不计入评价"，加分项只认"数据交互与持久化"，投入产出比极低            |

## 5. 开发框架（施工图）

### 5.1 分层架构

```
┌─ L5 行为层  js/*.js        只做行为，不写样式（运行时几何量除外）
├─ L4 页面层  pages.css      只做"页面独有的版式变奏"
├─ L3 组件层  components.css 每个组件一个 block，BEM 命名
├─ L2 布局层  layout.css     栅格 / 页头 / 幕间 / 页脚
├─ L1 基础层  base.css       reset / 排版 / 焦点 / 工具类
└─ L0 令牌层  tokens.css     颜色 / 光 / 字阶 / 间距 / 时长 / 缓动
```

**铁律**：L4 不得定义颜色字面量；L3 不得写页面选择器；L5 不得 `element.style.xxx =` 写视觉样式（仅允许写 CSS 变量，如 `--open`）。

> 拆分原则：**一个文件只回答一个问题**。`main.js` 现在 231 行管了 5 件事，压测时定位困难。

### 5.3 代码约定（10 条，写进 README 的"技术说明"）

1. HTML 只写结构；状态一律 `data-*`（`data-lit` / `data-open` / `data-level` / `data-dim`）。
2. JS 一律 IIFE + `'use strict'`，不污染全局；跨文件只暴露一个命名空间（如 `window.Lamp`）。
3. 不写内联 `style`；现有 16 处（`index.html:81,84`、`play.html:62,175` 等）全部迁入 CSS。
4. 事件用委托（`document.addEventListener('click', …)` + `closest()`），关节/纹样/工具不再逐元素绑定。
5. 动画只动 `transform` / `opacity` / `filter`；禁止动 `width/height/top/left`。
6. 每个可交互元素必须有 `hover / active / focus-visible / disabled` 四态。
7. 所有 JS 增强必须是"可缺失"的：禁用 JS 后，正文、时间轴、工序、流派、剧目**仍可读**。
8. `localStorage` 读写一律包 `try/catch`（隐私模式），键名统一前缀 `lamp:`。
9. 注释写"为什么"，不写"做了什么"；每个文件头 3 行说明职责 + 依赖。
10. 提交前 `grep -rn "console\.\|debugger\|TODO"` 必须为空。

### 5.5 光的三层模型（全站视觉的"物理引擎"）

```
--lamp-level 0.15 ──────────────────────────── 1
      │
      ├─ --ambient  环境光：底色明度、纸纹可见度、暗角浓度
      ├─ --key      主光：灯箱中心径向渐变、投影长度与模糊
      └─ --rim      边缘光：卡片 1px 金线、字口高光、SVG 描边亮度
```

- 只允许在 `body` 上改 `--lamp-level`，任何组件不得自设亮度。
- 剧场滑杆 → `--lamp-level`；点灯 → `0.15 → 1`，800ms `--ease`。
- 对比度保护：`--lamp-level < 0.5` 时，字幕块强制切到 `--paper` 并在下方垫 40% 黑，保证 ≥4.5:1。
