## 四、复跑方式（三条命令）

```bash
# 1. 合规审计（file:// 与 HTTP 各跑一遍）
node tools/audit.mjs web
python -m http.server 8765 --directory web
LAMP_ORIGIN=http://127.0.0.1:8765 node tools/audit.mjs web

# 2. 键盘通关 + 控制台
node tools/check.mjs web

# 3. 匿名版（自检不过会直接退出码 1）
node tools/anonymize.mjs web dist/匿名版
```

> 脚本会自动探测 Chrome / Edge；也可 `LAMP_BROWSER=<浏览器 exe 绝对路径>` 指定。
