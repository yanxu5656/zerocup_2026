## 一、给 B（李健豪 · SVG 素材）

### 总规范（所有交付通用）

| 项 | 要求 |
| --- | --- |
| 格式 | 纯 SVG，**不嵌位图**，不引外部字体，不加 `<filter>` 高斯模糊 |
| 颜色 | 只用这五个值（见 `web/assets/css/tokens.css`）：墨 `#241A12`、朱 `#B23A28`、石绿 `#3E6B4B`、藤黄 `#D9A02B`、皮白 `#F3E3C4` |
| 描边 | `stroke-linejoin="round"`，线宽 ≥ 2（缩放后不糊） |
| 尺寸 | 必须带 `viewBox`，不要写死 `width/height` |
| 命名 | 全小写英文 + 连字符，如 `pattern-huimen.svg` |
| 交付位置 | `web/assets/svg/` 下按子目录放：`patterns/`、`theater/`、`puppet/`、`diy/` |

> 一句话标准：**缩到 80px 还能认出是什么，放大到 800px 还能看见细节。**

### B-1 纹样 8 枚（最高优先，最能加分）

**现在的问题**：8 枚都是随手画的小图案，答辩时被问「这个叫什么」会答不上来。

| 编号 | 名称 | 结构要点（照着画，不要自由发挥） |
| --- | --- | --- |
| 1 | 回纹 | 连续回环的方形螺旋，转角必须方，不能圆 |
| 2 | 万字纹 | 卐 字连续咬合，笔画等宽，四向延展 |
| 3 | 缠枝纹 | 一根主藤 S 形贯穿，枝叶左右对称生长 |
| 4 | 冰裂纹 | 不规则三角与四边形拼合，**不能有平行线** |
| 5 | 云纹 | 如意云头，三层叠压，云的尾巴要卷 |
| 6 | 水纹 | 鱼鳞状连续弧线，排列成行，行间错位 |
| 7 | 龙纹 | 盘曲的 S 形躯干 + 鳞片刻线 + 四爪 |
| 8 | 寿纹 | 团寿字变形，笔画首尾相连成圆 |

- **画布**：`viewBox="0 0 240 240"`，图形外留 24px 边距
- **颜色**：单色墨 `#241A12`，**透明底**（页面会换底色）
- **工时**：每枚 40–60 分钟，一天可完成 3–4 枚
- **验收**：8 个文件放进 `patterns/`，我在 `future.html` 里替换后，缩略图和弹窗都清晰不糊

### B-2 剧场三出戏的人物（直接补最大短板）

**现在的问题**：剧场里的影人冠像梳子、身体是一团，且和舞台的彩皮不是一套画法。

三出戏，每出 2–3 个人物，**画在 800×450 的画面里，人物高约 160–200**：

| 出目 | 需要的人物 | 姿态 |
| --- | --- | --- |
| 三打白骨精 | 孙悟空、白骨精 | 悟空举棒、单腿；白骨精扬袖 |
| 劈山救母 | 沉香 | 双臂举斧过头 |
| 断桥 | 白娘子、许仙 | 白娘子撑伞，许仙侧身 |

- **画法**：侧身（皮影永远是侧脸），头大身小、手臂过膝，这是皮影的造型规律
- **上色**：脸/手用皮白，衣袍用朱红或石绿，冠用藤黄，**所有轮廓用墨线勾**（线是皮影的命）
- **工时**：每个人物 1.5–2 小时
- **验收**：缩到 200px 宽仍能分辨是谁、在做什么动作

### B-3 舞台影人的头茬 ×3

**现在的问题**：舞台上那个影人的脸是空的，看不出行当。

只画**头部**，复用现有身体骨架：

- **画布**：`viewBox="0 0 120 140"`（头 + 冠 + 须）
- **三个行当**：
  - 净（武将）：花脸、豹头环眼、有髯口
  - 旦（女角）：细眉、小口、贴片
  - 丑（丑角）：短须、圆眼、滑稽
- **关键**：眼部要**镂空**（用 `fill-rule="evenodd"` 挖洞），光从孔里透过去
- **工时**：每个 1 小时
- **验收**：换头之后，三个人物并排放在一起，能一眼分出谁是谁

---

### C-1 剧场三出戏的唱词（最高优先）

**现在的问题**：三出戏只有一句台词，撑不起"看戏"的感觉。

每出 **6–8 句**，每句 **≤ 18 字**（字幕框放不下更多），并且要标出**动作点**：

```
三打白骨精
1. 师父，山那边来了个送饭的姑娘。      ← 悟空警觉，后退半步
2. 你这妖怪，敢在俺老孙面前弄鬼！      ← 举棒
3. 一棒下去，只见一股青烟……          ← 棒落
```

- **必须标注**：哪一句对应哪个动作（举棒 / 转身 / 亮相），我会按这个去排动画
- **工时**：3 小时
- **验收**：我填进 `theater.js` 的 `PLAYS` 后，字幕不换行、不溢出，节奏能跟上
